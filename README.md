## 🌎 Sobre o projeto

O **Compass** é uma plataforma desenvolvida para centralizar informações e facilitar a comunicação entre cidadãos, ONGs e administradores durante situações de desastres ambientais.

Seu propósito é contribuir para a organização de ocorrências, solicitações de ajuda e recursos de apoio às comunidades afetadas.

## ⚙️ Funcionalidades

- **Área pública:** informações, alertas, avisos e pontos de apoio.
- **Cidadãos:** solicitações de ajuda, denúncias, publicações e comunicação.
- **ONGs:** ambiente para organizações cadastradas.
- **Administradores:** gerenciamento de usuários, ocorrências, denúncias, recursos, alertas e relatórios.

## 🚀 Instalação

**Requisitos:** PHP, MySQL/MariaDB, Apache e XAMPP ou ambiente equivalente.

1. Clone o repositório:

   ```bash
   git clone https://github.com/SouzaGuui/Compass.git
   ```

2. Coloque o projeto na pasta `htdocs` do XAMPP.

3. Inicie Apache e MySQL.

4. Crie o banco de dados `compass` no phpMyAdmin e importe o arquivo SQL de demonstração.

5. Configure as credenciais locais do banco e do SMTP, sem publicar informações privadas.

6. Acesse:

   ```text
   http://localhost/compass/
   ```
