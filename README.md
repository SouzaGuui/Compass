# Compass — Environmental Crisis Management System

A web platform developed to support communities affected by environmental disasters.

## Overview

Compass is an academic software development project designed to centralize emergency information, support requests, alerts and assistance resources.

## Main Features

- Emergency alerts and notifications.
- Citizen support requests.
- Occurrence and report management.
- NGO management.
- Communication system.
- Support points management.
- Administrative dashboard.
- User authentication and access control.
- Weather information integration.

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Architecture

The application is organized into public pages, citizen and NGO environments, administrative modules, API endpoints and a relational database.
